# ZU4EV H.264 UVC Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development for independent domains and focused tests.

**Goal:** Hardware H.264 USB UVC with independent raw DP display.
**Architecture:** Raw capture buffers have explicit independent readers; encoded
access units use separate bounded buffers. Integrate VCU and UVC end to end.
**Tech Stack:** C11, Linux 6.12/Xilinx 2025.1, configfs UVC, Vivado Tcl, SystemVerilog as needed.
**Spec:** ../specs/2026-11-01-zu4ev-h264-uvc-design.md

## Global constraints

Preserve DP YUY2, Ibex ISP control, 1280x1024 120/60 fps, and noncoherent DMA
ownership. NV12 conversion uses separate buffers; CPU cost must be measured.
No generated-output scans, no flash writes, no edits to existing untracked files.

## Review focus

DP and encoder completion in either order; USB stop with DMA still active;
compressed reference-frame ordering; header/IDR restart after reconnect;
actual VCU driver/firmware and frame-based kernel compatibility.
