# NV12 DDR writer micro-architecture

## Frozen contract
Single 200 MHz clock, synchronous active-low reset. WIDTH and HEIGHT positive even constants. AXI4 write-only, 128-bit data, 32-bit byte addresses, single ID implicit zero; connect unused AXI attributes at integration. Descriptor base and stride must be 16-byte aligned, stride >= WIDTH, extent base + stride*(HEIGHT+HEIGHT/2) <= 2^32. Padding is untouched. Y starts at base, UV at base+stride*HEIGHT.

Descriptor handshake transfers exclusive ownership of buffer/tag. Input begins only after descriptor acceptance and must start with first Y and first UV sample of that frame. Producer frame_abort invalidates the whole frame. The upstream non-stallable converter must propagate its overflow abort; arbitrary DDR stalls cannot be absorbed forever. No free descriptor means input is drained/discarded. A new descriptor is allowed only after the previous result is consumed AND the frame boundary is re-established by the integration controller. Never requeue a consumer-owned buffer. This module supports buffer rotation through tagged descriptors, but does not implement a software-visible descriptor ring.

## Decomposition and storage
Two nv12_plane_fifo instances own packing and bounded storage: each accepts one 16-bit pair per clock and emits 128-bit beats with byte strobes. A row tail flushes partial beats. The FIFO uses a registered synchronous memory read port plus one head register for stable ready/valid. Input packing owns column, row, EOF validation and a 128-bit partial word. FIFO depth is a power of two, at least 32 beats (default 256 = 4096 bytes per plane). No CDC. Packer error flags EOF at the wrong sample; source abort clears incomplete frames only after the AXI transaction drains.

Writer controller owns descriptor, Y/UV addresses, remaining row beats, outstanding burst and result. Pack FIFOs can fill concurrently with AXI drain. Arbitration alternates eligible planes. Eligible means enough beats for min(16, row remainder, 4KiB remainder), or final packer EOF. A burst never crosses a row or 4KiB boundary. AW, W, B retire independently: IDLE -> WRITE -> RESPONSE -> IDLE. All burst data is already buffered before AW. AWVALID/payload and WVALID/payload remain stable until handshake, even after abort. BREADY asserts only after AW and all W beats retire. One outstanding burst bounds response accounting; final result requires both plane counts exhausted, packer EOF, FIFO empty, and no outstanding write. Error/abort stops new bursts, drains an already-issued burst, then returns failed result; pending FIFO data is discarded on the next descriptor. Results remain stable until accepted. No timeout may manufacture a successful completion or release an outstanding transaction.

## State lifecycle and events
Descriptor acceptance clears packers, initializes address and row counters. Input_fire increments packer sample counters; packed_push writes FIFO, head_pop decrements occupancy. AW_fire clears AWVALID; W_fire increments burst count; B_fire samples BRESP. Reset clears ownership, pointers and valid bits, not memory. Reset during an outstanding write requires coordinated AXI fabric reset.

## Gate and verification
Unsigned widened 64-bit descriptor extent check prevents wrap. Tail strobe masks protect padding. Shared-clock packers are separate because each has independent valid/ready and memory ownership. FSM transition decode is separate from protocol data registers. Tests use an independent byte-addressed DDR model, randomized AW/W backpressure and B delays, response errors, aborts, result backpressure, two descriptors, row tails, 4KiB boundaries and full-resolution data. Resource/timing and PS-port integration are separate work; no claim of live VCU operation.

## ISP sink and buffer pool
nv12_isp_ddr_sink combines the converter and writer at a non-stallable final YUY2 tap. A descriptor is accepted only on a source SOF. Source frames without a descriptor are counted and ignored until the next SOF. Capture enable is latched at that SOF; converter abort or source fault invalidates the writer buffer. The sink always allows abandoned output words to drain when the writer has no owned descriptor. It provides no AXI-Lite register block; the external pool can queue available addresses before the frame starts.

nv12_buffer_pool owns four configured slots: FREE -> RESERVED while offering a stable descriptor -> WRITING on descriptor acceptance -> READY on successful response -> HELD on consumer delivery -> FREE on release. Failed results recycle only after the writer has drained B. Config is allowed only on unused/free slots, with no simultaneous descriptor/result/release events. Configured ranges must not overlap and the pool refuses invalid configurations. Allocation is round robin; READY delivery uses a four-entry completion FIFO and preserves writer completion order even across slot-index wrap. The consumer receives a tag identifying the slot, base and stride, and returns the tag after VCU use. READY metadata is latched so result backpressure is stable. Reset must be coordinated with VCU and AXI; it invalidates all slot ownership.

Timing refinement: row/plane beat counters use parameter-bounded widths. Each plane owns an explicit row-base register, so a row transition is one base+stride addition, independent of arbitration and burst-length arithmetic. Burst limits are 5-bit quantities (1..16).


## Safe stop (ENABLE/STOP/IDLE)
Control reset defaults ENABLE=0. CONTROL bit1 is ENABLE, bit0 IRQ enable; COMMAND=8 is STOP (clear ENABLE). STOP acknowledgement means accepted, not drained. STATUS bit2 IDLE asserts only while disabled, with no owned writer descriptor, no result pending, no AW/W/B transaction and no converter output/capture pending. IDLE is a PL DMA quiescence guarantee, not a VCU ownership guarantee. Completed/consumer-held pool slots are retained; STOP never releases VCU-owned memory. Existing descriptors can be reused on a later ENABLE, so software must preserve their mappings unless the whole peripheral/pool is reset while idle. Clearing mappings requires both PL IDLE and VCU completion; after mappings are freed ENABLE is forbidden until coordinated reset/reconfiguration.

Same-cycle STOP and source SOF: combinational stop_request from the accepted command has priority over descriptor allocation and new input. CONTROL clearing ENABLE has the same immediate gate. Disabled input never reaches the converter and does not increment no-buffer drops. STOP faults the converter and writer; an already-issued burst must keep AW/W payload and VALID stable and send all W beats, then wait indefinitely for B if necessary. There is no unsafe timeout. Unissued FIFO/partial data is discarded by next descriptor initialization. Idle cannot assert while a failed result awaits pool retirement or an output is stalled. ENABLE during drain returns SLVERR. Restart is accepted only after IDLE, starts only at a subsequent source SOF, and resets plane packers through descriptor acceptance. Existing completed frames/IRQ remain available after stop. Reads and result/consumer operations remain usable while stopped.

Lifecycle: DISABLED_IDLE -> RUNNING on ENABLE; RUNNING -> DRAINING on STOP/disable; DRAINING -> DISABLED_IDLE once writer, result and converter drain. No new FSM is needed in data path: ENABLE gates source acceptance and the existing abort/drain FSM owns AXI completion. Writer exports quiescent from its existing ownership/state flags. Reset is still not a substitute for STOP while an AXI transaction is live.

Verification gate: STOP at source SOF, blocked AW, blocked W, B wait, FIFO-full and completed-frame boundary; no early IDLE; stable AW/W; B must retire before IDLE; no new DDR accesses under continued source traffic after IDLE; repeated STOP; reject premature ENABLE; full-frame restart and byte comparison. AXI register STOP completion is distinct from IDLE and both must be checked.
