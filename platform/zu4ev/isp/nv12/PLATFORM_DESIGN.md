# Platform NV12 integration
SC130_NV12 is an opt-in build define. Final ISP converted/cv/cs/ce and packet_d/fault_d feed the peripheral after TNR. Existing YUY2 capture/DP remain connected. NV12 is a 128-bit write-only master on memory_xbar S06 into HP0. Control uses M09, A0080000/64KiB, a separate IRQ1 concat (PL IRQ1 bit0, INTID136 / DT SPI104). Actual PS HPM0/control/memory/HP0 and peripheral all use video_clk_in=200MHz and video reset; no new CDC is required. Existing CSI and TNR CDC remains unchanged.
Driver allocates four coherent buffers with 32-bit DMA mask; allocations persist across stream stop/start. DMA-BUF attachment maps use the importer device. IRQ takes completed frames only after B responses. VCU imports with V4L2_MEMORY_DMABUF; only input DQBUF returns capture ownership. STOP timeout pins potentially live buffers and poisons the session. Opt-in --nv12 bypasses CPU conversion.
